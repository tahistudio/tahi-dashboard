## Rules every slice follows

These are repeated here once so each brief can point at them.

1. Existing primitives win over the prototype. The prototype's `.inv`/`.fin` kit, `head-band.css` band and hand-drawn charts are NOT carried into the app. Map them: headline band to `KPIStrip`/`KPICell` (`components/tahi/kpi-strip.tsx`); left rail to `RailLayout` (`components/tahi/rail/rail-layout.tsx`) with `RailViewItem`, `RailSelect`, `RailGroupLabel`, `buildRailChips` (`components/tahi/rail/rail-controls.tsx`), composed the way `app/(dashboard)/clients/_list/clients-rail.tsx` does; tables to `DataTable` (with `mobileCard` for phones, `selectable` plus `BulkActionBar` for bulk); cards to `Card`; slide-overs to `SlideOver`; confirms to `ConfirmDialog`; menus to `Menu`; empty, error and denied states to `EmptyState` inside a `Card padding="none"`; skeletons to `SkeletonKPIStrip`, `SkeletonTable`, `SkeletonCard`, `SkeletonBar` (`components/tahi/skeletons.tsx`); meters to `ProgressBar`; charts to `BarChart`, `DonutChart`, `LineChart`, `FunnelChart` (`components/tahi/chart.tsx`); notes to `Callout`; money to `Money` and `useDisplayCurrency`; buttons to `TahiButton`; inline editors to `InlineNumberField` (`components/tahi/inline-field.tsx`); client picker to `SearchableSelect`; section jump nav to `SectionTabs`; statuses to `InvoiceStatusBadge` (`app/(dashboard)/invoices/invoice-status.tsx`) and the existing subscription badge. Grep `app/(dashboard)/design-system/design-system-content.tsx` and `components/tahi/` before writing any new piece.
2. The invoice status vocabulary stays the live one (Draft, Sent, Viewed, Overdue, Paid, Written off) from `InvoiceStatusBadge`. The prototype says "Opened"; the port keeps "Viewed", because the studio and portal vocabularies must never diverge (requirement section 1 and acceptance 1).
3. Tokens only (`var(--color-*)`, `var(--badge-*)`, `var(--radius-leaf*)`, `var(--space-*)`); no hex anywhere in these files (the sidebar is not in this module). Spacing in rem. No single-side borders (row hairlines come from the primitives). Leaf radius on primary CTAs, icon tiles and avatar wrappers only.
4. Every interactive element has a hover and a visible focus state (`tahi-focus-ring`); nothing is revealed on hover alone; touch targets are 2.75rem (44px) below `md` (use the primitives' own `min-h-11 md:min-h-*` classes; add `min-h-11` where a bare link or button is the only way in).
5. 375px with no horizontal scroll on the page frame; 768px checked; dark mode with the `.dark` class, no contrast loss. Tables become `mobileCard` rows below `md` rather than scrolling sideways.
6. Every money figure and client name carries `data-private` so private mode blurs it. Aggregates follow the nav currency switcher through `useDisplayCurrency`; a single invoice keeps its own currency with the display equivalent under it.
7. Honest surfaces only: no control the backend cannot do, no figure computed from a partial read without saying so, no copy that claims something the route does not do.
8. No em or en dashes in code, comments or copy. No `console.log`, no `any`, no commented-out code. `npm run type-check`, `npm run lint` and `npm run build` pass before pushing. Every page keeps its `export const metadata`.
9. Definition of Done (CLAUDE.md rule 8): live smoke on the deployed URL, 375px, dark mode, and a note in the commit body saying what was seen. The commit body also says "ported, unchecked" and names this plan.
