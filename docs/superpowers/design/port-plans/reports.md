1. lib/first-response.ts (pure, unit tested). Input rows { id, requestId, conversationId, orgId, authorId, authorType, createdAt }. Thread key: requestId, else conversationId, else 'org:' + orgId. Walk each thread in createdAt order: the first contact message after the last team reply opens a wait; the next team_member message closes it and records { authorId, orgId, minutes, clientAt }; further contact messages inside an open wait do not restart it; bot rows are skipped; a wait still open at the end counts as awaiting. Export computeFirstReplies(rows, { now, windowDays }) returning current-window replies (clientAt within the last windowDays), previous-window replies (the windowDays before that) and the awaiting count, plus median(values). lib/first-response.test.ts (Vitest): burst timed from the first client message; attribution to the replying member; bot skipped; unanswered counts as awaiting; split across the two windows; org-level thread fallback; median of odd and even counts.

Resolve scopedOrgIds(auth) from lib/access-scope.ts: kind none returns { items: [], summary with nulls, scoped: true } without querying; kind some filters messages.orgId. Read messages created in the last 60 days where isInternal is false or null, deletedAt is null, authorType in (contact, team_member, bot), selecting only the columns above, ordered by createdAt. Resolve authorId to a team member by teamMembers.id, then teamMembers.clerkUserId. Response { items, summary, scoped }. items: one per member with at least one first reply in either window, sorted by firstReplies desc: { teamMemberId, name, title, avatarUrl, firstReplies, medianMinutes, slowestMinutes, previousMedianMinutes (null when none), previousFirstReplies, messageCount (external team messages in the last 30 days), avgResponseMinutes (real mean, kept for MCP and old callers) }. summary { windowDays: 30, firstReplies, medianMinutes, slowestMinutes, awaitingReply } with nulls when no replies. Delete Math.random.
